Metrics

% Resolved
Named the right cause and explained its mechanism from a check that shows it. Unfinished trials count as not resolved.
Right cause
Final hypothesis is the true one.
Changed course
The model's own stated belief, in both setups: of trials where the deploy led right before the version check, the share where it no longer led right after.
Blamed deploy
Final answer blamed the deploy.
Cited a trap
Cited a failed or empty query as evidence.
To cause
Mean checks until the model's own top hypothesis was the true cause. Lower is faster.
Checks
Mean checks run per trial.
Tokens
Mean reasoning-model tokens per trial, input plus output. Jev's are not included.
Time
Mean wall time per trial.

Run it on your model

Any Anthropic model or OpenAI-compatible endpoint. Keys come from environment variables.

git clone https://github.com/mingleiw/jev-oncall
cd jev-oncall
export ANTHROPIC_API_KEY=... OPENAI_API_KEY=... TYPESAFE_API_KEY=...
python3 rca_experiment.py --check --models openai:your-model
python3 rca_experiment.py --models openai:your-model \
  --trials 5 --forced --html rca_report.html

Frozen evidence, fixed check menu, answers kept in separate files the agent never sees. Few trials per system: read the intervals before the ranks.
